AtlasAR viewer SDK

The same viewer as the AtlasAR WordPress plugin, for any website. Add ?model=mdl_… to this page's address to show one of your AtlasAR Cloud models, or ?src= with a GLB link.

1. Inline viewer

<atlasar-viewer model="mdl_…"></atlasar-viewer>

2. Button that opens a popup

<atlasar-viewer model="mdl_…" display="popup" button-label="View in 3D"></atlasar-viewer>

3. Custom AR button, auto-rotate, loads on click

<atlasar-viewer model="mdl_…" ar-button="custom" ar-button-text="See it in your room"
    ar-button-background="#0f766e" auto-rotate load="interaction"></atlasar-viewer>

4. Browsers that cannot show 3D

Forced here with renderer="fallback": the poster (or 360° images), and on a phone a "View in your room" link to its own AR app.

5. From JavaScript

const viewer = AtlasAR.mount('#from-code', { model: 'mdl_…', autoRotate: true });
viewer.element.addEventListener('atlasar:ready', (e) => console.log(e.detail.renderer));
